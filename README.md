# Anti-Game Controller

- Не храните пароль по умолчанию в рабочей установке.

Anti-Game Controller — приложение для Windows, которое помогает ограничить доступ к играм и игровым сайтам. Программа работает в фоновом режиме, завершает выбранные процессы, блокирует домены через системный файл и предоставляет локальную веб-админку для управления несколькими компьютерами.
## Возможности

- Блокировка процессов по имени `.exe`.
- Блокировка сайтов через `C:\Windows\System32\drivers\etc\hosts`.
- Защита критичных действий паролем.
- Полноэкранный режим фокусировки с блокировкой выхода без специальной комбинации.
- Автозапуск.
- Защита процесса приложения от завершения.
- Системный трей и работа в фоне.
- Профили конфигурации с импортом и экспортом JSON.
- Drag & drop конфигурационных файлов в окно приложения.
- Локальная сеть: автоматический выбор HOST и CLIENT.
- Веб-админка для просмотра компьютеров, отправки команд и назначения профилей.
- QR-код для быстрого открытия админки с телефона или планшета.
- Автоматические обновления из GitHub Releases проекта.

## Требования

- Windows 10 или новее.
- Доступ к локальной сети для сетевого управления.
- Права администратора для функций, изменяющих системные настройки.

## Установка из исходников

Клонируйте репозиторий и перейдите в его каталог:

```powershell
git clone https://github.com/AkiraShiro/antigamecontroller.git
cd antigamecontroller
```

Создайте виртуальное окружение и установите зависимости:

```powershell
py -m venv venv
.\venv\Scripts\Activate.ps1
py -m pip install --upgrade pip
py -m pip install -r requirements.txt
```

Если PowerShell запрещает запуск скриптов в текущем процессе, выполните:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
```

## Запуск

Запустите приложение из активированного виртуального окружения:

```powershell
py main.py
```

При первом запуске создается зашифрованный конфиг. Пароль по умолчанию: `1234`. После первого запуска его рекомендуется изменить во вкладке **Настройки**.

## Основные настройки

### Блокировка процессов

1. Откройте вкладку **Процессы**.
2. Введите имя процесса, например `RobloxPlayerBeta.exe`.
3. Добавьте его в список.
4. Нажмите **Применить изменения** и подтвердите действие паролем.
5. Запустите защиту.

### Блокировка сайтов

1. Откройте вкладку **Сайты**.
2. Добавьте домен без протокола, например `youtube.com`.
3. Примените изменения и запустите защиту.

Приложение добавляет записи в отдельный маркированный блок. При остановке защиты этот блок удаляется, а DNS-кэш очищается.

### Режим HOST

Во вкладке **Настройки** включите флажок **Сделать этот ПК главным (HOST)** и нажмите **Применить и перезапустить агента**. Выбор сохраняется в конфигурации и применяется после следующих запусков программы.

Если флажок выключен, компьютер участвует в автоматическом выборе роли CLIENT или HOST. Админка доступна по адресу, который отображается в сетевых настройках и QR-коде.

## Профили

Доступны следующие операции:

- сохранить текущие настройки как профиль;
- загрузить профиль как активный;
- импортировать JSON под паролем;
- экспортировать активную конфигурацию;
- удалить профиль под паролем.


## Сборка EXE

Установите PyInstaller:

```powershell
py -m pip install pyinstaller
```

Соберите основное приложение:

```powershell
.\build.bat
```

Готовый файл будет создан здесь:

```text
dist2\AntiGameController.exe
```

Сборка деинсталлятора:

```powershell
.\build_uninstaller.bat
```

Результат:

```text
dist2\AntiGameControllerUninstaller.exe
```

Деинсталлятор удаляет задачи автозапуска, записи блокировки из `hosts`, конфигурацию, профили, сетевую базу и защищенную копию приложения.

## Безопасность и ограничения

- Сетевой сервер рассчитан на работу внутри доверенной локальной сети.
- Не открывайте порт админки в интернет без отдельной настройки аутентификации и сетевого экранирования.
- Системные изменения требуют аккуратного использования: перед применением блокировок убедитесь, что домены и процессы указаны правильно.
- Не храните пароль по умолчанию в рабочей установке.
