# Anti-Game Controller

Anti-Game Controller — приложение для Windows, которое помогает ограничить доступ к играм и игровым ресурсам.

Текущая версия: `0.18`.

## Возможности

- блокировка запуска выбранных игровых приложений;
- блокировка указанных сайтов;
- полноэкранный режим фокусировки;
- защита критичных действий паролем;
- сохранение нескольких профилей настроек;
- импорт и экспорт профилей;
- локальная веб-панель для управления компьютерами;
- работа в системном трее;
- автоматическая проверка обновлений.

## Быстрый старт

1. Запустите приложение.
2. При первом запуске используется пароль `1234`.
3. Откройте **Настройки** и смените пароль.
4. Добавьте программы и домены для блокировки.
5. Нажмите **Применить изменения**.
6. Запустите защиту.

## Блокировка приложений

Откройте вкладку **Процессы**, укажите имя исполняемого файла, например `RobloxPlayerBeta.exe`, и добавьте его в список.

## Блокировка сайтов

Откройте вкладку **Сайты**, укажите домен без `http://` или `https://`, например `youtube.com`, и примените настройки.

## Профили

Профили позволяют сохранить отдельный набор настроек и быстро переключаться между ними.

При импорте и обновлении конфигурации старые параметры автоматически дополняются актуальными значениями.

## Локальная панель

Если в сети есть несколько компьютеров, они могут управляться через локальную веб-панель.

Адрес панели и QR-код отображаются в настройках приложения.

## Обновления

Программа может проверять новые сборки на GitHub Releases.

Проверку также можно запустить вручную во вкладке настроек.

Перед обновлением сохраните открытые документы и файлы.

## Решение типичных проблем

- Запускайте приложение от имени администратора.
- Проверьте правильность имени программы или домена.
- Для локальной панели все компьютеры должны находиться в одной сети.
- Если приложение заблокировано антивирусом или SmartScreen, проверьте доверие к скачанному EXE.
- Откройте основной лог для подробностей:

```text
%APPDATA%\AntiGameController\logs\antigame.log
```

# Техническая документация

## Требования

- Windows 10 или новее;
- Python 3.11 рекомендуется для запуска из исходников;
- права администратора нужны для системных блокировок;
- локальная сеть нужна для сетевого управления.

## Запуск из исходников

```powershell
py -m venv venv
.\venv\Scripts\Activate.ps1
py -m pip install --upgrade pip
py -m pip install -r requirements.txt
py main.py
```

Основные зависимости: PyQt5, psutil, cryptography, pynput и qrcode.

## Сборка основного EXE

```powershell
.\build.bat
```

Готовая сборка:

```text
dist2\AntiGameController.exe
```

## Структура проекта

- `main.py` — интерфейс и основная логика;
- `watchdog.py` — логика фонового наблюдения;
- `autostart_manager.py` — автозапуск;
- `config_manager.py` — конфигурация;
- `config_storage.py` — профили;
- `network_agent.py` — сетевой клиент;
- `network_server.py` — локальный веб-сервер;
- `hosts_manager.py` — блокировка доменов;
- `process_manager.py` — работа с процессами;
- `auto_updater.py` — обновление;
- `build.bat` — сборка приложения.

## Ограничения

- Сетевой порт предназначен для доверенной локальной сети.
- Не открывайте сервер наружу без дополнительной защиты.
- Блокировка процессов и доменов требует аккуратной настройки.
